Get your serving key

  1. Open API Management in Azure portal and select the serving APIM resource.
  2. In its left menu, go to APIs → Subscriptions.
  3. Find Content Understanding client (foundry-content-understanding-sub), reveal its Primary key, and copy it.
  4. Paste the key here and choose Use key for this tab. This section collapses when the key is in memory; reopen it to change or clear the key.

One APIM key authorizes submissions and polling for both CU backends. Your Azure CLI sign-in only authorizes the optional Azure controls; it does not replace this key.

Memory only. Analysis goes directly to APIM; this key is never sent to the local Azure control helper. Reloading clears it and all operation history.
